## Anatomical targeting diagrams

All 31 `anatomy.webp` images are custom vector illustrations generated specifically for IronTrack to illustrate the primary muscle target with an accent glow and list secondary assisting muscle groups. They are bundled under CC0 / Public Domain for IronTrack.

## App icons

`public/icon.svg` and the raster PNG set (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`) are original IronTrack artwork generated for this project.

## Fonts

The UI uses the system font stack; no webfonts are bundled or attributed.
